# Memark's public pages

The Privacy Policy that the app (`LegalLinks.privacyPolicy`) and App Store
Connect link to. `privacy/index.html` is built from
`docs/privacy-policy.md` in the Memark repository; edit that, rebuild, and
copy this folder to the public `initial-lab/memark-legal` repository,
which serves it with GitHub Pages at
https://initial-lab.github.io/memark-legal/privacy/.
